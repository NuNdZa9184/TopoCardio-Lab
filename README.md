# TopoCardio Lab — Топологический анализ данных (TDA) ЭКГ

**TopoCardio Lab** — нативное научно-исследовательское десктопное приложение на Python (**PySide6 + pyqtgraph + OpenGL**) для оцифровки бумажных сканов электрокардиограмм (ЭКГ), реконструкции фазового пространства (вложение Такенса) и расчёта топологических инвариантов (персистентные гомологии $H_0, H_1$).

Приложение разработано для научных исследований и подготовки курсовых / дипломных работ по топологическому анализу данных (TDA) биомедицинских сигналов.

---

## 🌟 Основные возможности

### 1. Интеллектуальная оцифровка сканов ЭКГ (`core/digitizer.py`)
- **Метод динамического программирования (Viterbi / DP)**: автоматический поиск пути минимальной стоимости слева направо с оптимизированным штрафом за вертикальные скачки ($\lambda \cdot \Delta y^2$), игнорирующий вертикальные артефакты разметки ленты (как на `ЭКГ(1).png`).
- **Подавление сетки миллиметровки**: цветовая фильтрация (выделение чернил на фоне розовой/зелёной сетки) и морфологическая селекция фоновых линий.
- **Классический поколоночный метод**: сохранён как альтернативный режим для сравнительного анализа.
- **Нативное разрешение**: сохранение непрерывной пиксельной траектории без принудительного сжатия, перевод в миллисекунды и милливольты через калибровку (`px_per_mm`, скорость 25/50 мм/с, вольтаж 10 мм/мВ).
- **Генератор синтетических сканов ЭКГ**: моделирование синусового ритма, экстрасистолии и фибрилляции предсердий с наложением сетки и шума для метрологической оценки точности (RMSE, коэффициент корреляции Пирсона $r$).

### 2. Реконструкция фазового пространства (`core/embedding.py`)
- **Вложение Такенса**: $\mathbf{x}(t) = [x(t), x(t+\tau), \dots, x(t+(d-1)\tau)]$.
- **Средняя взаимная информация (AMI)**: автоматический расчёт кривой $AMI(\tau)$ с детекцией первого локального минимума для строгого математического обоснования задержки $\tau$.
- **Метод ложных ближайших соседей (FNN)**: оценка доли ложных соседей для обоснования минимальной достаточной размерности вложения $d$.

### 3. Вычислительное ядро TDA (`core/tda_engine.py`)
- **Персистентные гомологии через Ripser**: фильтрация Виеториса–Рипса для размерностей $H_0$ (компоненты связности) и $H_1$ (одномерные циклы/петли аттрактора).
- **Расширяемый реестр метрик (`@register_metric`)**:
  - `max_h1_persistence` — максимальное время жизни цикла в $H_1$;
  - `mean_h1_persistence` — среднее время жизни циклов в $H_1$;
  - `persistent_entropy_h0`, `persistent_entropy_h1` — персистентная энтропия Шеннона;
  - `h1_l2_norm` — $L_2$-норма персистентностей ($H_1$ топологическая амплитуда);
  - `wasserstein_distance`, `bottleneck_distance` — топологические расстояния Вассерштейна и Боттлнека относительно эталонного участка («Норма»).
- **Суррогатный тест AAFT**: амплитудно-согласованная фазовая рандомизация с расчётом $z$-score и $p$-value для доказательства нелинейности динамики сердечного ритма.

### 4. Наборы данных и базы PhysioNet (`core/datasets.py`)
- Загрузка локальных сканов (`.png`, `.jpg`, `.bmp`) и предустановленные конфигурации участков.
- Подключение к базе данных аритмий **PhysioNet MIT-BIH** через `wfdb` с локальным кэшированием.

## 🖥️ Структура пользовательского интерфейса

Приложение разделено на три функциональные вкладки:

1. **Вкладка 1 — Интерактивный анализ (ROI):**
   - Интерактивный просмотрщик скана с поддержкой нескольких перетаскиваемых рамок выделения (ROI).
   - Кнопка **«Зафиксировать как Эталон (Норма)»** — фиксирует диаграмму персистентности текущего участка для автоматического расчёта расстояний Вассерштейна и Боттлнека для всех остальных участков.
   - Живые регуляторы предобработки (метод DP / поколоночный, порог, окно сглаживания) и параметров вложения ($\tau$, $d$, кнопка «Авто (AMI)»).
   - Синхронизированные графики: оцифрованный сигнал $x(t)$, трёхмерный вращающийся аттрактор Такенса с градиентной шкалой времени (OpenGL), диаграмма персистентности ($H_0, H_1$).
   - Таблица вычисленных TDA метрик в реальном времени.

2. **Вкладка 2 — Обоснование параметров и валидация:**
   - График $AMI(\tau)$ с вертикальным маркером выбранного минимума.
   - График доли ложных соседей $FNN(d)$ для размерностей $d = 1 \dots 6$.
   - Панель суррогатного теста AAFT: гистограмма распределения метрики суррогатов, линия реального сигнала, $z$-score, $p$-value и автоматическое заключение о значимости нелинейной структуры.

3. **Вкладка 3 — Пакетный эксперимент и экспорт:**
   - Сводная таблица с рассчитанными топологическими метриками.
   - **Универсальная пакетная обработка файлов:** выбор нескольких файлов сканов или папки, автоматический расчёт центральных полос.
   - **Расчёт всех активных ROI:** пакетный расчёт всех размеченных рамок текущего скана.
   - Экспорт в **CSV** и **Excel (.xlsx)** с форматированием.
   - Экспорт публикация-готовых фигур высокого разрешения (**300 DPI .png** и векторный **.svg**) с русскоязычными подписями осей для вставки в научный отчёт.

## 🚀 Установка и запуск

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.9+ (проверено на Python 3.10–3.14). Установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запуск тестов
Для проверки корректности работы всех модулей:
```bash
python -m pytest tests/ -v
```

### 3. Запуск приложения

**Способ 1 (через пакетный файл Windows):**
Дважды щелкните по файлу `run.bat` в папке проекта.

**Способ 2 (через командную строку):**
Обязательно перейдите в папку с проектом перед запуском:
```cmd
cd /d F:\ЭКГ
python main.py
```

## 📊 Математический аппарат

1. **Вложение Такенса (Теорема Манэ–Такенса):**
   При задержке $\tau$ и размерности $d \ge 2 d_A + 1$ гладкое отображение восстанавливает топологию фазового аттрактора динамической системы сердца.
2. **Персистентная энтропия:**
   $$H(D) = -\sum_{i=1}^n p_i \ln p_i, \quad p_i = \frac{d_i - b_i}{\sum_{j=1}^n (d_j - b_j)}$$
   где $b_i, d_i$ — время рождения и смерти $i$-й топологической особенности.
3. **Расстояние Вассерштейна между диаграммами персистентности:**
   $$W_p(D_1, D_2) = \left( \inf_{\gamma} \sum_{x \in D_1} \|x - \gamma(x)\|_\infty^p \right)^{1/p}$$
